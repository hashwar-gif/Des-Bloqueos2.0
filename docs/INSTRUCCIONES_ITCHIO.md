======================================================================
   DESBLOQUEOS BOLIVIA v2.7 — Instrucciones de Descarga e Instalación
   Plataforma: itch.io
======================================================================

1. REQUISITOS MÍNIMOS
----------------------------------------------------------------------
- Navegador web moderno (Chrome, Firefox, Edge, Safari)
- Conexión a internet (para cargar Bootstrap y Google Fonts vía CDN)
- Resolución mínima recomendada: 360x640 (móvil) o 800x600 (PC)
- JavaScript habilitado en el navegador


2. CÓMO JUGAR (SIN DESCARGA)
----------------------------------------------------------------------
El juego se publicará en itch.io como juego web (HTML5).
Simplemente:

  1. Ve a la página del juego en itch.io
  2. Haz clic en el botón "RUN" o "PLAY"
  3. El juego se cargará directamente en el navegador
  4. ¡No necesitas instalar nada!


3. DESCARGA PARA JUGAR OFFLINE (ZIP)
----------------------------------------------------------------------
Si quieres descargar el juego para jugar sin internet:

  OPCIÓN A — Desde itch.io:
  1. Ve a la página del juego en itch.io
  2. Busca el botón "DOWNLOAD" o "Download Now"
  3. Selecciona "DESBLOQUEOS_BOLIVIA_v2.7.zip"
  4. Guarda el archivo en tu computadora

  OPCIÓN B — Desde este repositorio:
  (Si tienes acceso al código fuente)


4. INSTALACIÓN (VERSIÓN DESCARGADA)
----------------------------------------------------------------------
  1. Extrae el archivo ZIP descargado
  2. Abre la carpeta extraída
  3. Haz doble clic en el archivo "index.html"
  4. El juego se abrirá en tu navegador predeterminado
  5. ¡Listo! Haz clic en "EMPEZAR MISIÓN" para jugar

  Alternativa:
  - Si tienes un servidor local (XAMPP, WAMP, etc.):
    Copia toda la carpeta dentro de "htdocs" y accede vía
    http://localhost/BLOQUEOS_BOLIVIA/


5. CONTROLES
----------------------------------------------------------------------
  Acción       | Teclado   | Móvil
  Moverse      | ← →       | Botones ◀ ▶
  Saltar       | Espacio   | Botón ⬆
  Disparar     | X         | Botón 🔥
  Habilidad    | Z         | Botón ⚡ HAB
  Saltar diálogo | X       | Botón CONTINUAR


6. PUBLICACIÓN EN ITCH.IO (para el desarrollador)
----------------------------------------------------------------------
  Al publicar en itch.io, selecciona:

   - Project type: "HTML"
   - Sube los siguientes archivos/carpeta:
     • index.html
     • game.js
     • style.css
     • api/leaderboard.php
     • assets/music/ (con canciones)
     • README.md
     • docs/DESCRIPCION.md

  - Viewport dimensions: 800 x 400
  - Mobile-friendly: Sí
  - Kind of project: Game


7. NOTAS IMPORTANTES
----------------------------------------------------------------------
  - El juego requiere internet para cargar Bootstrap 5 y Google Fonts.
  - En móvil, girar el dispositivo a horizontal (landscape) para
    mejor experiencia.
  - Los controles táctiles aparecen automáticamente en dispositivos
    móviles.
  - Para una experiencia óptima, usa Chrome o Firefox actualizados.
